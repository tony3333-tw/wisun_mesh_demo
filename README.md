# wisun_mesh_demo

Erlang border router for a 6LoWPAN/RPL mesh (Contiki-NG nodes in Cooja first,
real boards later), in the style of lora_mesh_demo. Planned path to Wi-SUN.

- `wisun_mesh/` – Erlang app (Apache-2.0)
- `wisun_mesh/test/captures/br_cooja_ref.pcap` – reference SLIP traffic from Contiki-NG's native border router
